¿Necesitas ayuda de Serenazgo?

Selecciona el tipo de incidente para iniciar tu solicitud. Esta plataforma busca ser inclusiva y accesible para todos los ciudadanos.

🔊 ¿No estás seguro? Selecciona una opción para leer su descripción. En una emergencia con peligro inmediato, contacta también a los servicios de emergencia correspondientes.
Paso 1 de 3 · No necesitas crear una cuenta para comenzar.

¿Dónde ocurre el incidente?

Busca una dirección o usa el GPS del dispositivo. También puedes hacer clic en el mapa para marcar el punto exacto.

📍 Ubicación del incidente

El mapa muestra Google Maps centrado inicialmente en la UPN Chorrillos. Busca una dirección o utiliza el GPS para registrar el punto exacto. El mapa necesita conexión a internet.

Ubicación pendiente: selecciona un punto en el mapa o busca una dirección.

Evidencia adicional (opcional)

Puedes adjuntar una fotografía o audio para explicar mejor la situación. No es obligatorio.
